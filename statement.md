# Project Statement

## Problem Statement
Introduction Many students wish to enhance their vocabulary skills, but to learn new words by regular method can sometimes be tedious. This project is a simple Word Scramble Game where the user has to unscramble the jumbled alphabet and identify the word that is formed. This game makes vocabulary practice interesting.

## Scope of the Project
* This project is intended for simple vocabulary exercise and amuse.
* You can select a difficulty mode and then challenge yourself to find the correct all words.
* We run this in the python terminal without requiring any additional software or installed packages.
* In the coming time, more words, level of difficulty, scores, and more features of the game can be added in the game to make it interesting.

## Target Users
The game is mainly useful for:
* School and college students
* Beginners learning Python
* Just people like to use common English words people will use.
* Anyone for a little fun, simple word game?

## High-Level Features
The main features of the game are:
* Level of dificulty Easy, Medium, Hard
* Genders are randomly picked for each game
* Letters of the word are scrambled
* The player is allowed a few guesses of the word
* Score is shown after the game
* Simple command-line interface
* Option to play the game again
* No external Python packages are required
